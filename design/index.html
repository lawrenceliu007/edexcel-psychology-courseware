01四个决策：这轮课到底怎么上

决策 1 · 第一节课讲考试，还是直接讲考纲内容？
答：两件都做，但顺序是「先给一个能记住的现象，再给地图，最后看卷子」。不建议整整一节纯讲考纲。
理由：学生对「考试结构」没有既有图式（schema）。先讲 15 分钟 Unit / Section / AO / command word，他们能记住的比例很低；但「65% 的普通人会把一个陌生人电到致死电压」这句话有极强图式。所以第一节课用现象做钩子（hook），把考试地图挂在这件事上面，学生才有地方放这些信息。
决策 2 · 教学顺序照考纲走吗？
答：Topic 顺序照考纲（A→B→C→D），但每个 Topic 内部要重排三处。
照 Topic 顺序，是因为 Unit 1 就是 A+B、Unit 2 就是 C+D，而且 method 的依赖链刚好顺着走（List A 在 Topic A 教 → List B 在 Topic B 教 → Topic C 复用 List A → Topic D 复用 List A+B）。
重排的三处是：① 方法提到内容后面、实操前面，而不是放在每个 Topic 的最后一块；② Topic B 的推断统计（Wilcoxon）前置到 Sec B 计算类题训练之前；③ 实操（practical）必须在课内真做一遍，不能只讲。
决策 3 · 要不要先啃真题再写课件？
答：要，而且已经做完了。11 套 WPS01（2019 Jan – 2025 Jun）+ 5 套 WPS02 已经拉到本地并逐题结构化。设计里的每一个课时配比，都由这几个数字决定，不靠直觉。
决策 4 · 重心放哪里？
答：放在「定量数据」和「应用题（scenario application）」，而不是只堆理论背诵。
11 套 WPS01 里，涉及定量数据处理（集中趋势、离差、图表、百分比、正态分布）的题 43 处，平均每套 3.9 处，是全卷覆盖面最大的一块。这类题答案是确定的，英语基础弱的学生也能练到满；而纯理论背诵题对他们性价比最低。

05第一课怎么上（90 分钟逐段教案）

第一课的目标不是讲完一个知识点，而是让学生同时拿到三样东西：一个记得住的现象、一张能定位自己的考试地图、一个「什么叫得分点」的判据。

时间环节做什么为什么这么排
0–15′Hook：你会按到多少伏？不讲定义。给出场景：一个陌生人答错词，你要按 15V…450V 的电钮。
  1. 先让学生匿名写下自己会停在第几档；
  2. 再报真实数据：Milgram baseline 里 65% 的人按到最高档 450V；
  3. 只问一句：是这些人是坏人吗？
制造一个强图式锚点。学生带着「我刚刚预测错了吗？」进入整门课，后面所有内容都能挂在这上面
15–35′考试地图（20 分钟讲完，不多讲）一张图讲清：AS = 两张卷（WPS01 64 分 / WPS02 96 分）→ 四个 Topic（A 社会 / B 认知 / C 生物 / D 学习）→ 每个 Topic 都是「内容 + 方法 + 研究 + 实操」四件套 → 每张卷都是 Section A + B + 一个大题 Section C。
再给时间换算：90 分钟 / 64 分 ≈ 每分 1.4 分钟		现在才介绍考试，因为学生已经有了「服从」这个具体例子，知道「这门课学的是这种行为」，地图就有地方挂了
35–55′什么叫一个得分点用 January 2025 Q5(2 分) 做示范：Adjoa 不喜欢辣但还是跟朋友去了辣餐厅，要求「Describe, using conformity, why…」。
  1. 给学生看两份真答：A 份 0 分（"She conformed because she wanted to fit in with her friends"）；B 份 2 分（点出 normative social influence + 紧扣她不想被群体排斥）；
  2. 让学生自己说出差别：A 是泛论（generic），B 把理论接到了具体细节上；
  3. 念 mark scheme 原文给他们听："Generic answers score 0 marks"。
这是全学年最重要的一次评分体验。学生必须亲眼看到「写得像人话 ≠ 有分」，后面所有答题训练才有抓手
55–80′正式进内容：Obedience 的定义 + Milgram baseline术语先教后用：obedience（服从）的定义 → 三层区分（obedience vs conformity vs compliance）→ Milgram 1963 baseline 的程序（40 人 / 电击器 / learner-teacher / 四句 prods）→ 回到开头的锚点：65% 意味着什么第一节课的内容部分不要贪多。只做定义 + baseline 程序，把 variation studies 留给第 3 讲
80–90′收束 + 作业发 guided notes workbook 第 1 页；作业是 workbook 上的 2 道小题（一道 define，一道 application），10 分钟内能完成第一节课的作业要能做完。做不完的作业会让学生第二次课就不交

第一课不建议做的事

  • 不建议整节课串讲考纲条目——11 套真题已经证明，真正频繁出现的条目不到 20 条，重复率很高，可以在用到时再给编号。
  • 不建议第一节就讲 Agency Theory / Social Power Theory 两套理论——学生在没有 baseline 细节的情况下无法理解理论在解释什么。
  • 不建议第一节就布置 8 分 essay——会直接劝退。

06课程骨架：为什么是这个顺序

6.1 大顺序：A → B → C → D

理由说明
试卷就是这么排的WPS01 = Topic A + Topic B，WPS02 = Topic C + Topic D。上课顺序和答卷顺序一致，学生每次模考都能对应到"这块我学过"。
方法课的依赖链顺着走List A（描述统计）在 Topic A 教 → List B（推断统计）在 Topic B 教 → Topic C 明确只要 List A → Topic D 明确只要 List A + List B。考纲自己就是按这个依赖写的。
语言难度递增Social 最贴近日常经验，认知词汇适中，Biological 是纯术语（hippocampus / suprachiasmatic nucleus / zeitgeber），Learning 的概念最抽象（vicarious reinforcement / countertransference）。从易到难，学生在遇到最难的术语时已经有了答题习惯。

6.2 每个 Topic 内部的六个阶段（不是考纲给的排列顺序）

考纲里每个 Topic 的顺序是 Content → Methods → Studies → Practical。我建议每个 Topic 内部改成这个节奏：

阶段做什么对应考纲块理由
① 现象先给具体行为/现象（一个真实现场、一段视频、一个小互动）Content 的一半具体到抽象。Topic A 从 Milgram 数字开始，Topic B 从"你能同时听歌和背单词吗"开始
② 解释理论 / 模型 / 类型学Content 的另一半有了①的具体素材，模型和抽象概念才有依附
③ 方法这个 Topic 专属的方法 + 配套统计Methods必须先于⑤学会这套工具，否则实操做不出来
④ 研究Classic study + Contemporary study 各一篇Studies studies 的作用是"给前面 ③ 的方法一个真实的样板"，放这里让学生看到方法真的长什么样
⑤ 实操课内真做一次 + 写 Procedure / Results / DiscussionPracticalevidence：8/11 套卷有一道实操反思题；不做就白丢 4–8 分
⑥ 考试实验室只练题：8 分 essay + 2 道 application + 配套真题—把上面的知识转成得分能力，这是每 Topic 的收口

09需要你拍板的 5 件事

1 · 总课时是多少？
上面的课时表按 32 讲 × 90 分钟设计。如果你的实际排课是 24 讲或 20 讲，我按第 07 节末尾的压缩方案调整，但要你确认哪些 Topic 可以砍深度。
2 · Topic A 的 ch1-obedience 怎么处理？
现有 ch1-obedience 已经覆盖了 1.1.1–1.1.3。三个选项：
(a) 保留，新增 a2-conformity 等其余章节与之并列（编号不统一）；
(b) 把 ch1 按新的 L1–L3 结构重拆（编号统一为 a1 / a2 / a3，内容与现有最新版一致，从最新 commit 起做）；
(c) ch1 原样不动，只按新结构增补 conformity 之后的章节。
我倾向 (b)，理由是课时表要能直接对应 courseware 目录，编号混乱会让后续接力变贵。
3 · 四个 Topic 的「当代研究二选一」选哪边？
必须现在定，因为整个班的教材、题库、作业都围绕选定的那一篇：
Topic A：Yi Huang (2014) 还是 Haun (2014)｜Topic B：Darling (2007) 还是 Sacchi (2007)｜Topic C：McDermott (2008) 还是 Hoefelmann (2006)｜Topic D：Prot (2014) 还是 Bastian (2011)。
真题里两者都出现过（例如 Yi Huang 2 处 / Haun 0 处；Darling+Sacchi 共 3 处），选定后我把另一篇从题库里标为「不练」。
4 · 本轮先做哪些讲？
建议先把 L1（第一课）+ L4（Conformity）+ L7（Methods I） 三讲做出来跑一轮课堂：
· L1 是新流程的第一个样本，上完才知道地图那 20 分钟够不够；
· L4 是 Topic A 最大的缺口（conformity 目前完全没有课件）；
· L7 的方法课决定了后面每个 Topic 实操能不能落地。
跑完一轮反馈后我再批量做 L5–L10。你要一次性做完 Topic A 全 10 讲也可以，那就等 上面的 (2)(3) 两题先定了。
5 · 每讲是否都配一本印刷版 workbook（notes.html + PDF）？
前面几章（ch7 / ch8 / ch16–21 / d20 / d21）都是「教学页 + workbook PDF」双份。双份的质量最好，但产出成本大概翻倍。是否继续沿用，还是本轮先出教学页、workbook 留待二轮？
