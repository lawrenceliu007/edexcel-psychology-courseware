2 · Methods Decision Map

Before you can use a method, you must know which one fits — start here

Step 1 · Levels of measurement（测量层次）

Every dataset falls into one of three levels. This decides which statistical test you may use.

LevelWhat it isEveryday exampleFeeds into
Nominal（类别）Named categories, no orderHair colour, gender, "peers vs older"Chi-squared
Ordinal（顺序）Ranked order, but gaps not equal1st/2nd/3rd place, a rating 1–5Spearman or Wilcoxon
Interval（等距）Equal gaps, a real zeroSeconds, a score out of 20Ranked first, then Spearman/Wilcoxon

Step 2 · Which of the three tests?（三个检验选哪个）

You want to test…Data typeDesignUse this test
A difference between two groupsNominal (categories)Independent groupsChi-squared（卡方）
A difference between two conditionsOrdinal (ranked)Repeated measures / matched pairsWilcoxon（符号秩）
A relationship / correlationOrdinal (ranked)Correlation (two co-variables)Spearman（等级相关）

Ask two questions, in order：

① Difference or correlation?

→ Correlation → Spearman

→ Difference → go to ②

② Nominal or ordinal?

→ Nominal (categories) → Chi-squared

→ Ordinal (ranked, related design) → Wilcoxon

中文理解：选检验就像点菜前先看菜单分类。先问「我比的是差异还是关系？」——比关系就用 Spearman；比差异再问「数据是分类（男/女、选A/选B）还是排序（第1名/第2名）？」——分类用卡方，排序（同一批人测两次）用 Wilcoxon。三步锁定，不用背。

3 · The 3 Statistical Tests — Step by Step

The section that wins or loses Section C — each test with a fully worked example from our courseware

Difference Nominal

Chi-squared（卡方检验）

When to use it：testing a difference between independent groups with nominal data（分类数据，如「选同伴 vs 选大孩子」）。

The recipe（步骤）：

  1. State the null hypothesis（零假设：没有差异）。
  2. Write the observed (O) frequencies you collected.
  3. Calculate expected (E) for each cell = (row total × column total) ÷ grand total.
  4. For each cell: (O − E)² ÷ E.
  5. Sum them → χ² = Σ (O − E)² ÷ E.
  6. Find df = (rows − 1) × (cols − 1).
  7. Compare χ² to the critical value in the exam table (df=1 → 3.84 at p≤0.05).
  8. χ² ≥ critical → significant → reject null; χ² < critical → not significant → retain null.

Worked example（WPS04 Q8，取自课件）：Lisa 观察女孩和男孩首选玩伴是「同龄人 peers」还是「大孩子 older」。结果：girls 18 peers / 9 older；boys 10 peers / 12 older。

CellOEO − E(O − E)²(O − E)² ÷ E
Girls–peers1815.43+2.576.610.43
Girls–older911.57−2.576.610.57
Boys–peers1012.57−2.576.610.53
Boys–older129.43+2.576.610.70
χ² = Σ (O − E)² ÷ E2.23

Conclusion：χ² = 2.23, df = 1, critical value = 3.84. Since 2.23 < 3.84, we retain the null hypothesis — there is no significant difference between girls and boys in their first choice of play partner.

结论模板：「The observed value of χ² (2.23) is less than the critical value (3.84, df = 1, p ≤ 0.05), so we retain the null hypothesis — there is no significant difference between…」
中文理解：卡方就是「实际看到的人数 vs 假设没有差异时应看到的人数」。每一格都算 (O−E)²÷E 再加总，得到 χ²。χ² 比临界值大才显著（拒绝零假设），小就保留（无显著差异）。本题 2.23 < 3.84，所以「男孩女孩选玩伴没有显著差异」。这题还考过最简比 18:10 = 9:5。
Correlation Ordinal

Spearman's Rank（斯皮尔曼等级相关）

When to use it：testing a relationship / correlation between two co-variables with ordinal data（可排序）。

The recipe（步骤）：

  1. Rank both columns separately（最高分排第 1，次高第 2…）。
  2. For each participant: d = rank A − rank B.
  3. Square every d → d²（消除负号）。
  4. Sum → Σd².
  5. Substitute: r_s = 1 − (6Σd²) ÷ (n(n² − 1)).
  6. Give r_s to 2 decimal places.
  7. Compare |r_s|（看绝对值，不看正负）to the critical value in the table. |r_s| ≥ critical → significant.

Worked example（取自 ch17）：10 名学生，「复习小时数 hours」与「考试分数 mark /20」求相关。Σd² = 26.5, n = 10。

r_s = 1 − (6 × 26.5) ÷ (10 × (100 − 1)) = 1 − 159 ÷ 990 = 0.839 ≈ 0.84

Interpretation：r_s = 0.84 is a strong positive correlation（复习越多，分数越高）。Compare 0.84 to the table's critical value for n = 10 (≈ 0.65 at p ≤ 0.05) — since 0.84 ≥ that, the result is significant, so we reject the null hypothesis.

结论模板：「The observed value of r_s (0.84) is greater than the critical value (0.648, n = 10, p ≤ 0.05), so we reject the null hypothesis — there is a significant positive correlation between hours of revision and test marks.」
中文理解：斯皮尔曼看的是「两个变量一起变」的程度。r_s 在 −1 到 +1 之间：越接近 +1 正相关越强，越接近 −1 负相关越强，接近 0 没相关。看绝对值，+0.84 和 −0.84 都算强。第二道题（CBT 次数 vs 攻击行为，Σd²=224, n=9）算出 r_s ≈ −0.87，就是强负相关。
Difference Ordinal

Wilcoxon Signed Ranks（威尔科克森符号秩检验）

When to use it：testing a difference between two conditions in a repeated measures (or matched pairs) design with ordinal data（同一批人测「之前 vs 之后」）。

The recipe（步骤）：

  1. For each participant, find difference = after − before.
  2. Remove any zero differences（这些参与者不计入 N）。
  3. Rank the differences by size（忽略正负号），最小的排 1。
  4. Give each rank a + or − sign according to the difference's direction.
  5. Add the positive ranks → T⁺; add the negative ranks → T⁻.
  6. T = the smaller of T⁺ and T⁻.
  7. Compare T to the critical value in the table. T ≤ critical → significant → reject null.

Worked example（取自 ch25）：Zuzanna 观察 9 名精神分裂症患者，在家人探访「之前」和「之后」各测一次症状（repeated measures）。她用非方向假设，做 Wilcoxon，得到 T = 4，且没有零差。

N = 9（无人被剔除）。查表：双尾 p ≤ 0.05，N = 9 的临界值 T = 6。

Conclusion：observed T (4) is less than or equal to the critical value (6) → the result is significant → she rejects the null hypothesis（家人探访对症状有显著影响）。

结论模板：「The observed value of T (4) is less than or equal to the critical value (6, N = 9, p ≤ 0.05), so we reject the null hypothesis — there is a significant difference in symptom severity before and after family visits.」

最容易记反的规则

Wilcoxon 和卡方方向相反：Wilcoxon 的观察值 T 必须≤临界值才显著（越小越显著）；卡方和斯皮尔曼是观察值≥临界值才显著（越大越显著）。

中文理解：Wilcoxon 专门对付「同一批人测两次」的差异题。它把「变化的大小」排成秩，看正变化和负变化谁更强。记住：T 越小越显著，和卡方/斯皮尔曼反过来——这是学生最容易丢分的地方。

4 · The 17-Point Methods Checklist（9.1.1–9.1.17）

Every methods spec point, with a plain definition + a life analogy + a self-check

9.1.1

Types of Data（数据类型）

  • Qualitative（质化）：文字/描述，如访谈记录。Quantitative（量化）：数字，如分数。
  • Primary（一手）：研究者自己收集的。Secondary（二手）：别人收集好的（如已有报道、数据库）。
  • 类比：qualitative 像「写日记」，quantitative 像「称体重」；primary 像「自己做菜」，secondary 像「分析别人做的菜」。
说出一个研究里 primary + qualitative 数据的例子。
9.1.2

Sampling Techniques（抽样方法）

  • Random（随机）：每个人都有同等机会被抽中，像抽签。
  • Stratified（分层）：按比例先分组再随机抽，像「先按班级比例再抽签」。
  • Volunteer（自愿）：贴海报等人主动报名。
  • Opportunity（机会）：选最容易抓到的人，像「路过就抓」。
哪种抽样最容易有「样本偏差 bias」？为什么？
9.1.3

Experimental Designs（实验设计）

  • Independent groups（独立组）：两批不同的人各测一次。
  • Repeated measures（重复测量）：同一批人测两次（有顺序效应 order effects）。
  • Matched pairs（配对组）：两两配对，像双胞胎各进一组。
  • 类比：独立组像「A 班和 B 班各考一次」，重复测量像「同一班考两次」，配对像「按水平结对再分组」。
Repeated measures 的一个弱点是什么？（提示：order effects）
9.1.4

Hypotheses（假设）

  • Null（零假设）：预测「没有差异/关系」——是默认要被检验推翻的。
  • Alternate / experimental（备择/实验假设）：预测「有差异/关系」——你想证明的。
  • Directional（定向/单尾）：预测了方向（「A 组更高」）。Non-directional（非定向/双尾）：只预测「有区别」，不说方向。
  • 类比：null 像「被告无罪」的默认立场，alternate 像「原告要证明有罪」。
写一个「睡眠影响记忆」实验的 null + alternate hypothesis。
9.1.5

Questionnaires & Interviews（问卷与访谈）

  • Open（开放式）问题：自由作答。Closed（封闭式）：固定选项，含 ranked scale（如 1–5 打分）。
  • Structured（结构化）：照稿问。Semi-structured（半结构化）：有提纲但可追问。Unstructured（非结构化）：自由聊。
  • 这些得到的都是 self-report data（自我报告数据）。
Closed question 的一个优点是「易量化」，说出它的一个缺点。
9.1.6

Experiments（实验）

  • Laboratory（实验室）：控制强、可重复，但像「白大褂环境」生态效度低。
  • Field（现场）：在真实场景做，更自然，但难控制。
  • IV（自变量）＝研究者操纵的；DV（因变量）＝测量的结果。
  • 类比：IV 是「你调的水温」，DV 是「水温影响下长出来的芽高」。
一个 field experiment 比 lab 好在哪、差在哪？
9.1.7

Observations（观察）

  • Covert（隐蔽）vs overt（公开）；participant（参与）vs non-participant（不参与）；structured（结构化）vs naturalistic（自然）。
  • Tallying（划记）：数行为出现次数。Event sampling（事件取样）：只记特定事件。Time sampling（时间取样）：固定间隔记一次。
  • 既能收 qual 也能收 quant 数据。
Covert 观察的一个伦理问题是什么？
9.1.8

Correlation（相关）

  • Positive（正相关）：同升同降。Negative（负相关）：一个升一个降。
  • 相关 ≠ 因果：相关不能证明一个变量导致另一个变量，可能有其他变量（第三变量）。
  • 类比：冰淇淋销量和溺水人数都上升，不是冰淇淋导致溺水，而是「夏天」这个第三变量。
为什么相关研究「不能 claim causation」？
9.1.9

Additional Methods（其他方法）

  • Twin studies（双生子，看基因 vs 环境）、animal experiments（动物实验）、case studies（个案，如脑损伤病人与记忆）。
  • Brain scanning（CAT / PET / fMRI）、RCTs（随机对照试验）、content analysis（内容分析）。
  • Clinical interviewing（临床访谈）、ethnographic fieldwork（民族志田野，如对儿童）、longitudinal / cross-sectional（纵向/横断）、cross-cultural（跨文化）、meta-analysis（元分析）。
Longitudinal 和 cross-sectional 研究各有什么优缺点？
9.1.10

Control Issues（控制问题）

  • Counterbalancing（平衡法）：抵消 order effects（顺序效应）。Randomising（随机化）：随机分配条件。
  • Demand characteristics（需求特征）：被试猜到目的就迎合。Social desirability（社会赞许）：说「好听的」答案。
  • Experimenter / researcher effects（实验者效应）：研究者无意中影响结果。
  • Participant / situational variables（被试/情境变量）、extraneous / confounding variables（额外/混淆变量）、operationalisation（操作化定义）。
  • 类比：confounding variable 像「偷偷混进菜里的盐」，让你说不清味道到底来自哪一味。
「operationalise aggression」是什么意思？给个可测量的定义。
9.1.11

Descriptive Statistics — List A（描述统计）

  • Central tendency（集中趋势）：mean（均值）/ median（中位数）/ mode（众数）。
  • Dispersion（离散）：range（全距）/ standard deviation（标准差）。
  • Graphs（图表）：bar chart（条形图）、histogram（直方图）、scatter diagram（散点图）。
  • Normal distribution（正态分布）vs skewed（偏态）；percentages（百分比）；sense checking（合理性检查）。
  • 注意：考试不需要背公式，但要会算步骤、会比较两组均值。
一组数据里有一个极端值，用 mean 还是 median 更能代表「典型」？为什么？
9.1.12

Inferential Statistics — List B（推断统计）

  • 三个检验：Wilcoxon / Spearman / chi-squared（详见 §3）。
  • Levels of significance（显著性水平）：p ≤ .10 / .05 / .01。One-tailed vs two-tailed（单尾/双尾）。
  • Type I error（假阳性：错拒绝了真的零假设）vs Type II error（假阴性：没拒绝假的零假设）。
  • Observed value vs critical value（观察值 vs 临界值）→ 决定 reject or retain null。
Type I 和 Type II error 各是什么？各举一个「误判」的类比。
9.1.13

Methodological Issues（方法论议题）

  • Validity（效度：测得准不准）— internal（内部）/ predictive（预测）/ ecological（生态）。
  • Reliability（信度：稳不稳定，重测结果是否一致）。
  • Generalisability（泛化性）、objectivity（客观性）、subjectivity（主观性）、credibility（可信度）。
  • 详见 §5 的完整对照表。
「有效度但没信度」可能吗？用「称体重」类比说明。
9.1.14

Thematic Analysis（主题分析）

  • 处理质化数据的方法：通读文字材料 → 找出反复出现的主题 theme → 归类编码 → 总结。
  • 类比：把一屋子散乱便利贴按主题归类，贴成几大块。
  • 与 content analysis（内容分析）区别：thematic 更偏「归纳主题」，content 更偏「数出现次数」。
给一段访谈记录做 thematic analysis，第一步做什么？
9.1.15

Conventions & Peer Review（写作规范与同行评审）

  • 报告结构：abstract（摘要）→ introduction（引言）→ aims & hypotheses（目的与假设）→ method（方法）→ results（结果）→ discussion（讨论）。
  • Peer review（同行评审）：投稿前由领域专家匿名审稿，把关质量。
Peer review 的一个优点和一个局限？
9.1.16

Ethics — Humans（人类伦理）

  • BPS Code of Ethics and Conduct (2009)：知情同意、保密、退出权、避免伤害、事后说明 debrief。
  • Risk assessment（风险评估）在研究前必做。
  • UNCRC（儿童权利公约）：研究儿童时 participation vs protection rights（参与权 vs 保护权）。
  • HCPC（健康与护理专业委员会）：临床从业者的准则。

9.1.17

Ethics — Animals（动物伦理）

  • Scientific Procedures Act 1986（科学程序法）＋ Home Office Regulations（内政部条例）：控制动物实验。
  • 核心原则：减少伤害、替代动物（3R：Replace / Reduce / Refine）。

6 · Key Questions（9.2 关键议题速查）

Section D · 8 marks · one key question in society

One 8-mark question (AO1 4 + AO2 4). The paper gives you a key question for society（社会关键议题）and two or three named studies. "Generic answers score 0 marks" — you must tie everything to the specific context given.

The four-move framework（四步法）

  • ① Define：说清这个 key question 是什么。
  • ② Apply theory：用相关理论/概念解释。
  • ③ Apply research：引用指定研究（AO2 关键）。
  • ④ Answer：回到问题，给出结论。

AO2 — the part that scores

  • 每引用一个研究，必须说清它如何帮助回答这个具体问题。
  • 用「in the context of…」把理论和情境连起来。
  • Worked example：职场霸凌 + 媒体与进食障碍（见 Ch27）。
中文理解：Section D 是「给你一个社会议题 + 指定研究，让你用心理学去回答」。得分点在于把研究和议题挂钩——只背研究不联系议题，0 分。完整四步法 + 范文见 Ch27 Key Questions。

8 · Common Exam Traps（常见考点陷阱）

The six mistakes that cost methods marks — read before the exam

① Correlation ≠ causation

相关不能证明因果。总有第三变量（third variable）可能同时影响两者。

写结论时只说「有关联」，不说「导致」。
② Wilcoxon 方向记反

Wilcoxon 的 T 越小越显著（≤临界值才显著）；卡方和斯皮尔曼是越大越显著。

背口诀：W 小、卡/斯 大。
③ One-tailed vs two-tailed

方向假设（「更高」）用单尾；只说「有差异」用双尾。用错会查错临界值。

先看假设有没有「more/less/higher」这类方向词。
④ Type I vs Type II error

Type I＝误拒真零假设（假阳性）；Type II＝漏拒假零假设（假阴性）。

I＝「冤枉好人」，II＝「放过坏人」。
⑤ 选错检验

数据是 nominal 却用了 Spearman，或 related design 却用了 chi-squared。

先跑 §2 的「两步判断法」再动笔。
⑥ 忘写结论

算出统计值却不写「reject/retain null」＋「显著/不显著」，白丢 1 分。

套 §3 的结论模板，永远用完整句式。
