2.2.12 INFERENTIAL STATISTICS
Probability · Significance · Type I/II errors · Levels of measurement · Wilcoxon signed ranks · 推断统计

Topic B · Cognitive psychology Methods Spec 2.2.12 📖 Textbook Book 1 · Ch.12 · pp.112–124

What this page is really asking

  1. A difference is never enough. Two conditions always differ somewhere; an inferential test decides whether that difference is a real effect or just chance — the same judgement as refusing to pay out on a coin that landed heads ten times.
  2. Psychology draws the line at 5%. p ≤ .05 means the "luck" explanation survives at most 1 time in 20, so the null is rejected; p ≤ .10 is too lenient, p ≤ .01 is highly significant, and nothing is ever "proved" — only supported.
  3. The line creates two errors. Too lenient risks a Type I (false positive); too stringent risks a Type II (false negative). Medicine uses 1% because a false drug approval is costlier than a missed effect.
  4. Then the mechanics. Name your data level (nominal vs ordinal-or-above), pick the test (chi-squared / Wilcoxon / Spearman's), compute T, compare calculated ≤ critical, and report all six pieces of the statistical statement.

Learning Objectives 学习目标

  • Explain what an inferential test does and why a visible difference between conditions is not, by itself, evidence of an effect.
  • Interpret the levels of significance p ≤ .10, p ≤ .05 and p ≤ .01, and state the correct decision at each.
  • Identify Type I and Type II errors in described scenarios and explain why different disciplines choose different levels.
  • Classify data as nominal, ordinal, interval or ratio, and choose the correct inferential test from the decision conditions.
  • Calculate the Wilcoxon signed ranks test (differences, ranks, T), compare it to a critical value, and write the full statistical statement.

1. Chance or a Real Effect?

Descriptive statistics — means, tables, graphs — describe a data set. But describing is not deciding. Two conditions will almost never produce exactly the same scores, so a difference between them always exists. The real question is whether that difference is a genuine effect of the independent variable or just chance variation between the two groups.

An inferential test of significance（推断检验：算出「这个结果纯靠运气出现的概率」的统计工具）answers exactly that question. It rests on one concept: probability（概率：某件事发生的可能性）。A fair coin has a probability of 0.5 of landing heads. Ten heads in a row is unlikely; one hundred heads in a row is so unlikely that you stop blaming luck and start blaming the coin. When a result becomes very unlikely under chance, some other factor — usually the manipulated IV — is the better explanation.

This is also where the null hypothesis does its job. It predicts no real difference: any difference found is due to chance. The inferential test tells you whether to reject the null (a real effect — accept the alternative) or retain（保留：不推翻）it (no real effect).

中文理解：推断检验回答的问题只有一个：「这个差别是巧合吗？」逻辑跟抛硬币完全一样。10 次里出 6 次正面你认，是运气；100 次全正面你不认，因为运气解释不通了。实验数据的差别也一样：小到运气能解释 → 保留虚无假设；小到运气解释不了 → 推翻虚无假设，承认是自变量真的起了作用。整页就围绕「这条线画在哪」展开。

2. The 5% Rule: Levels of Significance

So how unlikely must a result be before you blame the coin? Psychology draws the line at p ≤ .05（显著性水平：结果纯靠运气出现的概率上限）。If the probability of the result occurring by chance is 5 per cent or less — 1 in 20 — the result is significant（显著：够格推翻虚无假设）and the null hypothesis is rejected. If the probability is greater than .05, the result is not significant and the null hypothesis is retained.

Two other levels matter. At p ≤ .10 the result is still not significant, so the null is retained — but a 1-in-10 result may still be reported and followed up with more research. At p ≤ .01 the result is highly significant: there is a 1-in-100 probability of it being due to chance, and the null is rejected with extra confidence.

One warning the textbook underlines: even after a significant test we have not proved anything. We can only say the result reasonably supports the alternative hypothesis — or, if the test is not significant, that we are not confident enough and retain the null. Proof is not on the menu; support is.

中文理解：记住三个门槛和对应的决定。p ≤ .10：不显著，保留虚无假设（但可以继续研究）；p ≤ .05：显著，推翻虚无假设（心理学的默认线，1/20 的运气概率）；p ≤ .01：高度显著，推翻得更放心（1/100）。另一个铁律：统计永远不能「证明」假设，只能说「支持」，考试写「prove」会扣分，写「supports」才对。

3. Type I and Type II Errors

Wherever you draw the line, two wrong decisions are possible. A Type I error（第一类错误：把巧合当成了真效应，假阳性）is a false positive: the researcher rejects the null hypothesis when it is actually true — they claim an effect that was not real. A Type II error（第二类错误：把真效应当成了巧合，假阴性）is a false negative: the researcher retains the null when a real effect was there all along.

A real effect existsNo real effect
Reject the nullCorrect decisionType I error (false positive)
Retain the nullType II error (false negative)Correct decision

The level you choose is a trade-off between the two errors, and different disciplines draw the line differently:

  • Medical research uses p ≤ .01 — stringent. Approving an ineffective drug is too costly, so false positives (Type I) must be minimised. The price: with the bar that high, a genuine but modest effect may be missed — a Type II risk.
  • Exploratory research sometimes uses p ≤ .10 — lenient. Early studies use small samples, and missing something important (Type II) is the bigger worry. The price: more false positives slip through.
  • Psychology's p ≤ .05 is the compromise between the two risks.

中文理解：两类错误是一对跷跷板。门槛定得松（.10）→ 容易把巧合当真（第一类）；门槛定得严（.01）→ 容易把真效应漏掉（第二类）。记忆锚点：第一类 = 假阳性 = 「没病说有病」；第二类 = 假阴性 = 「有病说没病」。医学怕第一种（批了无效药），所以用 .01；探索性研究怕第二种（错过新发现），所以敢用 .10；心理学 .05 是折中。

4. Levels of Measurement

Before choosing a test you must know what kind of data you have. The four levels of measurement（测量水平：数据的类型）run from least to most informative:

  • Nominal（称名数据：只有类别和各类别的人数）— categories only. A class survey counts how many students own a pet and how many do not. We know the totals in each category and nothing about any individual value.
  • Ordinal（顺序数据：排得出名次、量不出差距）— ranked positions. Houses ranked first, second, third tell you the order but not the gaps: first may beat second by 10 points while third trails by 100. Ratings on arbitrary scales (grades, attractiveness 1–10) are ordinal because the intervals are not truly equal — someone rated 5 is not half as attractive as someone rated 10.
  • Interval and ratio（等距／等比数据：刻度均匀，差多少是真差多少）— recognised scales with equal intervals. Ratio data additionally has an absolute zero: height in centimetres, time in seconds, distance in kilometres all start at zero.

For choosing an inferential test you only need one distinction: nominal versus ordinal-or-above. Interval and ratio data can be treated as ordinal for test selection.

中文理解：判断数据水平问一句话：「数字之间能比出真差距吗？」只能数人头 → 称名；只能排名次、刻度是人定的 → 顺序；有统一刻度、差距是真的 → 等距／等比（等比多一个「真零点」：体重 0 kg 就是没有重量）。选检验时只用二分：称名，还是顺序及以上。

5. Choosing the Right Test

Three questions decide which inferential test fits your data:

  1. Are you investigating a difference or a relationship between variables?
  2. Is the design related (same or matched participants in both conditions) or unrelated?
  3. What is the level of measurement?

You are only required to learn three tests, and the textbook condenses the decision into one table:

TestConditions for use
Chi-squared test（卡方检验）A test of difference and association; nominal data is gathered
Wilcoxon signed ranks test（威尔科克森符号秩检验）A test of difference; ordinal (or above) data; a repeated measures design was used
Spearman's rank test（斯皮尔曼等级相关检验）A test of relationship/correlation; ordinal (or above) data

One design rule completes the table: a matched pairs design（匹配对设计：两组人按关键特征一一配对）is technically independent groups, but because the participants are matched, for test selection it is treated as a repeated measures design.

The choice also connects to your hypothesis. A directional hypothesis (direction predicted) leads to a one-tailed test（单尾检验）; a non-directional hypothesis leads to a two-tailed test（双尾检验）. The tail decides which column of the critical values table you read — you will see it in action below.

中文理解：选检验 = 回答三连问。找差别还是找关系？同一批人（或配对人）还是两批人？什么水平的数据？三问答完检验就定了：差别 + 称名 → 卡方；差别 + 顺序及以上 + 重复测量（含匹配对）→ 威尔科克森；关系 + 顺序及以上 → 斯皮尔曼。方向预测得出 → 单尾；预测不出 → 双尾。这一步错了，后面全错，所以选题的三个条件要在考场上先默背一遍。

6. Wilcoxon Signed Ranks, Step by Step

The Wilcoxon signed ranks test is used for a difference between two conditions, with ordinal-or-above data, in a repeated measures (or matched pairs) design. Here is the textbook's own example: ten participants recall words from a non-categorised list and from a categorised list. Does list type make a real difference?

The calculation, in five moves:

  1. Calculate the difference between each participant's pair of scores (A − B).
  2. Rank the differences, ignoring plus and minus signs. Equal scores share a divided rank: two 4s occupy positions 2 and 3, so each is ranked 2.5 — and the next score jumps to position 4.
  3. Sort the ranks into a rank-if-positive column and a rank-if-negative column. Participants with zero difference are ignored.
  4. Add up each column.
  5. The smaller total is the T value — the observed (calculated) value of the test.

The calculated value of T must be equal to or less than the critical value for significance at the level shown.

The hypothesis — more words will be recalled from a categorised list — is directional, so a one-tailed test at p ≤ .05 with n = 9 gives a critical value of 8. Our calculated value of 4.5 is less than 8: the result is significant, the null hypothesis is rejected, and we conclude that participants recall more words from a categorised list.

Finally, report the finding in a full statistical statement（统计报告句：把判断过程完整说出来的固定句式）, including all six pieces of information: the calculated value, the critical value, the number of participants, one- or two-tailed, the significance level, and the hypothesis decision. For example: "The calculated value of T = 4.5 was less than the critical value of 8 for a one-tailed test with n = 9. Therefore p < .05 and the null hypothesis can be rejected. This means that participants will recall more words from a categorised list than a non-categorised list." Note the symbols: significant results are reported as p < .05; non-significant ones as p > .05.

Before any of these numbers are trusted, run a sense check（数据合理性检查：动手算之前先目测估计结果）: glance at the data, predict roughly what the calculation should produce, and compare. If your predicted mean is around 5–6 but you calculate 50, you have almost certainly made an arithmetic error. In multi-step calculations like the standard deviation or the Wilcoxon ranking itself, this rough guess is the cheapest error trap you have.

Close the loop: back to the coin

The coin game and the word-list experiment are the same judgement. In the coin game, ten heads in a row has a tiny probability under chance, so you blame the coin. In the experiment, the inferential test computed the probability of the score difference arising by chance — and found it at or below 5 per cent (T = 4.5 ≤ critical value 8). The "luck" explanation collapses at the 5% line, so the IV — list type — is the better explanation. That is all an inferential test ever does: it weighs your result against pure chance and tells you which side of the line it falls.

Reflect before the Exam Lab: if another researcher repeated the word-list study and got T = 12 with n = 9, would they reach the same conclusion? Say the decision out loud before opening the next section.

中文理解：威尔科克森五步：算差 → 排秩（负号不看，同分平分秩位）→ 分正负两栏 → 各自求和 → 小的那栏就是 T。三条反直觉规则最容易丢分：① T 越小越显著（跟大多数检验相反），判断句是「计算值 ≤ 临界值 → 显著」；② n 要剔除差为 0 的人；③ 报告句六要素一个不能少（计算值 / 临界值 / n / 单双尾 / p 水平 / 假设决定）。动手算之前先目测一遍数据，结果离谱就说明算错了。

8. Exam Lab

Exam Practice: Bertrand's visuospatial game

Bertrand developed a visuospatial game to see if spatial awareness could be improved through practice using the game every day for a week. He scored participants' spatial ability before using the visuospatial game and again after a week. Scores: A 44→78, B 47→74, C 56→88, D 65→76, E 68→80, F 54→53.

Q1a · Calculate the Wilcoxon signed ranks test 4 marks

Copy and complete the table of differences and ranks, and calculate T.

Differences (after − before): A +34, B +27, C +32, D +11, E +12, F −1. Ranks (ignoring signs): 1 → rank 1, 11 → rank 2, 12 → rank 3, 27 → rank 4, 32 → rank 5, 34 → rank 6. Rank if positive: 6 + 4 + 5 + 2 + 3 = 20. Rank if negative: 1. The smaller total is T = 1.

Marking guidance: 1 mark for correct differences, 1 for correct ranks, 1 for correct column totals, 1 for identifying the smaller total as T = 1.

Q1b · Determine significance 2 marks

Determine whether Bertrand's results are significant for a one-tailed (directional) test at p ≤ .05.

n = 6 (no zero differences to exclude). For a one-tailed test at p ≤ .05 with n = 6, the critical value is 2. The calculated value T = 1 is equal to or less than the critical value of 2, so the result is significant: p < .05 and the null hypothesis can be rejected. Practice with the game improved spatial awareness.

Marking guidance: 1 mark for reading the correct critical value (2, for n = 6, one-tailed, .05), 1 mark for the comparison T = 1 ≤ 2 and the conclusion "significant".

Q1c · Describe p ≤ .01 2 marks

Bertrand decided to calculate whether his results were significant at the p ≤ .01 level of probability. Describe what is meant by p ≤ .01 in relation to Bertrand's investigation.

p ≤ .01 means there is a 1 per cent or less probability (1 in 100) that the difference in spatial scores between the two tests occurred by chance. It is a more stringent level of significance than p ≤ .05; if Bertrand's result is significant at .01, the improvement is highly significant and the null hypothesis can be rejected with greater confidence.

Marking guidance: 1 mark for stating the 1 per cent / 1-in-100 chance probability, 1 mark for linking it to significance of Bertrand's spatial-awareness difference.

Q1d · Strength of a sense check 2 marks

Explain one strength of Bertrand applying a 'sense check' to the data gathered in his investigation.

A sense check means glancing at the data first and predicting roughly what the calculation should produce before doing it. If Bertrand's rough prediction differs vastly from his actual calculated value, he knows to look for an arithmetic error before drawing any conclusion. This is especially valuable in a multi-step calculation like the Wilcoxon ranking, where one slipped rank would silently change the T value and could flip the significance decision.

Marking guidance: 1 mark for describing what a sense check does (predict before calculating), 1 mark for the consequence: catching calculation errors before they distort the conclusion.

Q1e · Why the Wilcoxon? 2 marks

Give two reasons why Bertrand used a Wilcoxon signed ranks test.

Reason 1: he was testing a difference between two conditions (before and after using the game), and the Wilcoxon is a test of difference. Reason 2: his design was repeated measures — the same participants were scored twice — and the spatial scores are ordinal level or above, which are exactly the Wilcoxon's conditions.

Marking guidance: 1 mark per correct reason from: test of difference / ordinal-or-above data / repeated measures (or matched pairs) design.

Exam Practice: Priya's memory training

Q2a · Is Priya's result significant? 2 marks

Priya carried out a Wilcoxon signed ranks test on her data to calculate the statistical significance for the difference in words recalled following a memory training exercise. The calculated value (T) was 8 (T = 8) for a two-tailed test at p < .05 with n = 10. Explain whether Priya's result is significant or not.

For a two-tailed test at p ≤ .05 with n = 10, the critical value is 8. The calculated value of T = 8 is equal to the critical value, and the rule is that the calculated value must be equal to or less than the critical value for significance. So the result is significant at p ≤ .05 and the null hypothesis can be rejected: the memory training made a genuine difference.

Marking guidance: 1 mark for the correct critical value (8, two-tailed, n = 10), 1 mark for the "equal to" comparison and the conclusion "significant".

Q2b · Level of measurement 2 marks

Explain the level of measurement recorded in Priya's experiment.

Priya recorded the number of words each participant recalled. This is a count on a recognised scale: the values have equal intervals and a true zero (recalling zero words means none were recalled), which makes it ratio level data. For the purpose of selecting an inferential test, ratio data can be treated as ordinal-or-above — one of the conditions that justified her using the Wilcoxon signed ranks test.

Marking guidance: 1 mark for identifying ratio (or interval/ordinal-or-above) level, 1 mark for justifying it with the properties of the scores (count, equal intervals, true zero).
